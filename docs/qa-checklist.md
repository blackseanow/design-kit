# 改动检查清单

改公共组件（kit 里的 CSS、JS、宏）或新增页面后，按下面的顺序检查。

## 1. 自动检查

```bash
cd design-kit
python -m unittest discover -s tests          # 颜色只在 Token 里、变量都有定义、图标存在、宏输出
node --test tests/js/kit.test.js              # 进度条、菜单定位、焦点、主题
PYTHON=python3 node tests/browser_check.js    # 浏览器交互（需要 playwright）
```

## 2. 尺寸

在下面 5 个宽度各看一遍：1440、1024、768、390、320px。

- [ ] 没有横向滚动条（表格容器内部滚动可以）
- [ ] 中文标题和按钮文字没有被挤压、截断或换成竖排
- [ ] 手机上按钮、菜单项、关闭按钮至少 44px

## 3. 主题

- [ ] 日间、夜间、跟随系统都切换一次
- [ ] 夜间没有出现白底块或看不清的文字
- [ ] 主按钮文字在品牌色上清楚（换了品牌色后要重新检查对比度）

## 4. 状态

每个列表或数据区都要有：

- [ ] 有数据
- [ ] 空状态（不显示假数字）
- [ ] 读取失败（显示原因和重试）
- [ ] 加载中
- [ ] 禁用状态的按钮和字段

## 5. 交互

- [ ] 下拉、日期、时间：能打开、能用键盘选、Esc 能关、关后焦点回到按钮
- [ ] 弹窗：打开后焦点在弹窗里，Tab 不会跑出弹窗，关闭后焦点回到打开它的按钮
- [ ] 弹窗里的菜单不被裁切，第一次 Esc 只关菜单
- [ ] 手机侧栏：打开、点导航、按 Esc、点遮罩都能关闭；点两级菜单的父项只展开，不关闭侧栏
- [ ] 抽屉：和弹窗一样检查焦点；手机上铺满宽度
- [ ] 弹出层、下拉菜单：点击外部关闭，Esc 回到按钮，不被表格或顶栏裁切
- [ ] 表格设置：隐藏列后刷新页面仍然隐藏；重置能恢复
- [ ] 表单提交后，原生字段的值正确（下拉、日期、时间增强后仍然提交原字段）

## 6. 真机和读屏（改公共组件后）

自动化只覆盖 Chromium、WebKit、Firefox 的桌面引擎和模拟尺寸。下面这些只能手动：

真机（iOS Safari 一台、Android Chrome 一台）：

- [ ] 弹窗里聚焦输入框，软键盘弹出后头部和底部按钮都还能看到，关闭键盘后布局恢复
- [ ] 抽屉铺满宽度，正文可滚动，底部按钮不被地址栏挡住
- [ ] 下拉、日期、时间菜单在键盘弹出时仍在可视区内，Esc 或点击外部能关闭
- [ ] 弹出层和下拉菜单不被顶栏或表格固定列盖住
- [ ] 横屏一次：弹窗高度跟随可视区域
- [ ] 320px 宽度无横向滚动

读屏（macOS VoiceOver + Safari，Windows NVDA + Firefox 或 Chrome）：

- [ ] 打开弹窗时朗读标题和说明，Tab 不会跑到背景；关闭后焦点回到打开它的按钮
- [ ] 下拉菜单朗读“菜单”，↑↓ 移动时逐项朗读；选项卡朗读“已选中”
- [ ] 加载遮罩开始时朗读“正在加载”，失败时朗读错误和“重试”
- [ ] 顶栏角标的未读数在按钮名称里（角标本身不朗读）
- [ ] 表单错误：聚焦字段时朗读错误原因

## 7. 代码

- [ ] 新 CSS 只用 `var(--…)`，没有写死颜色
- [ ] 没有在页面 CSS 里重新定义公共组件或 Token
- [ ] 图标用 `icon()` 宏或 `Kit.iconMarkup()`，新图标已加入 `icons.svg`
- [ ] 新的交互写进 `docs/interactions.md`
